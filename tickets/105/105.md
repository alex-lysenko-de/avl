Batch-скрипт для выполнения commit и push изменений в репозиторий.

Что сделать:
* `scripts/commit_push.bat` — принимает сообщение коммита аргументом (или спрашивает интерактивно, если не передано), делает `git add -A`, `git commit -m "<сообщение>"`, `git push origin main`;
* скрипт должен быть безопасным для пользователя: если нет изменений — сообщить и не падать; если push не удался — показать понятную ошибку, не откатывать ничего автоматически.

Зависит от тикета 104 (доступ к удалённому репозиторию).
