## Пересмотрено

Изначально тикет описывал упаковку в zip с `version.json` без фиксированного источника версии. После `wiki/update_workflow.md` формат уточнён и стал обязательным:

* версия берётся только из `pyproject.toml` (один источник истины, документ §35-36);
* в комплект входят `version.txt` и `manifest.json` (с SHA-256) — конкретные форматы заданы документом, §6-9;
* публикация пакета — через GitHub Releases (решено, не открытый вопрос — см. документ §4, §41: репозиторий публичный).
