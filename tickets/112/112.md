Дашборд тикетов.

Создать `tickets/dashboard.yaml` — компактный, машиночитаемый перечень всех тикетов и их текущих статусов.

Требования:
* каждый тикет — отдельная YAML-запись (id, title, status);
* без лишних полей (замечания/зависимости и т.п. намеренно не добавляются — компактность важнее);
* для дополнительной информации по тикету — отдельный файл `tickets/<id>/readme.md` (создаётся только когда реально есть что туда написать, не для каждого тикета);
* `status.txt` в папке тикета остаётся источником истины по статусу конкретного тикета; `dashboard.yaml` — агрегированная копия, которую нужно обновлять синхронно.
