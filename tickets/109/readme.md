## Пересмотрено

Изначально тикет описывал скелет отдельного `Updater.exe`. После `wiki/update_workflow.md` подход заменён: на этапе разработки полноценный Updater.exe не собирается — вместо него `update.bat` + `update.ps1` (документ §16-19, §53). Причины: проще менять механизм, проще диагностировать ошибки, не нужно поддерживать ещё один exe (документ §53).

`avl_docs/updater/` (пакет-заглушка из тикета 102) в этом подходе не используется; удалять его пока не будем — он не мешает и может пригодиться при переходе к полноценному Updater.exe в будущем (документ §54).
