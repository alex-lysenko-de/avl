## Пересмотрено

Согласно `wiki/update_workflow.md` (актуальное описание механизма обновления на этапе разработки), полноценный Windows-installer **не нужен**, пока приложение активно меняется (документ, §52). Установка на этапе разработки выполняется вручную один раз, дальнейшая доставка версий идёт через `update.bat` (см. тикет 109).

Тикет отменён, а не удалён — чтобы сохранить историю решения (Inno Setup был согласован пользователем как инструмент для дальнейшей стадии).

Документ прямо предусматривает возврат к installer/Updater.exe в будущем без изменения модели публикации релизов (документ, §54) — тогда этот тикет можно переоткрыть.
