## Пересмотрено

Изначально тикет был ограничен сборкой артефактов без внешней публикации (канал распространения ещё не был выбран). `wiki/update_workflow.md` явно фиксирует канал — GitHub Releases (§4, §41) — поэтому CI теперь должен публиковать Release с assets, а не просто складывать build-артефакты.
